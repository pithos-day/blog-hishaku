この記事は、カテゴリ機能の挙動を確認するためのデモ記事です。frontmatter の `categories` の書き方を試しています。

## 単一チェーン

```yaml
categories:
  - フロントエンド
  - Astro
```

`フロントエンド > Astro` の2階層カテゴリが作られます。この記事では `[ノート, カテゴリテスト]` を指定しています。

## 複数チェーン

```yaml
categories:
  - [フロントエンド, Astro]
  - [ライフ, 日記]
```

1つの記事に複数のカテゴリチェーンを付けられます。カテゴリツリーには両方の経路が反映されます。

## カテゴリ名のURLスラッグ化

`config/site.yaml` の `categoryMap` で、表示名からURLスラッグへの変換を定義できます。

```yaml
categoryMap:
  ライフ: life
  ノート: note
  ツール: tools
  フロントエンド: front-end
```

未登録のカテゴリ名は、そのまま(エンコードされて)URLに入ります。

## catalog: false

この記事には `catalog: false` を指定しています。このフラグを付けると:

- カテゴリツリーにノードとして現れない
- カテゴリページの記事リストに載らない
- カテゴリの記事件数にカウントされない

一覧・タグ・検索には通常どおり残ります。カテゴリの整理用に一時的に置く記事などに向いています。

## 確認手順

1. カテゴリページで `ノート > カテゴリテスト` が現れないことを確認する
2. 一覧にはこの記事が表示されることを確認する
3. 別記事で複数チェーンを指定し、カテゴリツリーに両方が現れることを確認する
