段落に X(Twitter) のステータス URL だけを書くと、ビルド時に fxtwitter API からデータを取得して静的ツイートカードに変換されます。この記事は、画像の枚数ごとの表示を確認するためのテスト用です。

## 画像なし

https://x.com/jack/status/20

## 画像1枚

https://x.com/NASA/status/2108662426606395572

## 画像2枚

https://x.com/NASA/status/2108285056170996122

## 画像3枚

https://x.com/SpaceX/status/2105867094457987377

## 画像4枚

https://x.com/NASA/status/2105698284354367897

## 動画付き

https://x.com/SpaceX/status/2108826911359050211

## 取得に失敗した場合

存在しない ID を指定すると、取得に失敗してもビルドは止まらず、ツイート URL のリンクとして残ります。

https://x.com/i/status/0000000000000000000

## テストチェックリスト

1. 画像なし — ヘッダー・本文・フッターだけのカードになる
2. 画像1枚 — カード内に全幅の画像が1枚表示される
3. 画像2枚 — 画像が横に2つ並ぶ (昔の Twitter 風)
4. 画像3枚 — 左に大きく1枚、右に上下2枚
5. 画像4枚 — 2×2 のグリッド
6. 動画付き — 動画プレイヤーではなくテキストのみのカードになる
7. 本文中の URL がリンク表示され、そちらのクリックでその URL へ遷移する
8. カードの他の部分 (画像・ヘッダー・フッター) をクリックするとツイート本体が開く
9. 本文が長く URL を含むツイートでも、カードが分断されず1つの枠に収まる
10. 取得失敗分のエントリが `.cache/og-data.json` に error としてキャッシュされる
